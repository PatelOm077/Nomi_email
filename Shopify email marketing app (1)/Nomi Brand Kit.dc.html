Color

Cyan carries interaction. Use #0088b0 for fills and large elements, and the darker #00789e for body-size text and links, where it clears contrast on white. Magenta is a spot color for one thing at a time, never a second UI color.

Type

Source Serif 4 owns the brand voice: wordmark, headings, landing page, marketing. Interface chrome inside Shopify admin uses the system sans, so Nomi sits with Polaris rather than against it and small labels stay legible.

Semibold 600 — headings and wordmark

Regular 400 — body copy and long-form

Italic 400 — captions, quotes, asides

System sans — admin UI chrome: labels, buttons, fields, tables

In email, webfonts get stripped by Gmail and Outlook. Always set the stack as Source Serif 4, Georgia, serif — Georgia is installed everywhere and holds the newsprint tone in any inbox.

Voice

Say what the app does, not what it unlocks. Short sentences, no exclamation marks.

Speak to a shop owner with limited time. Name the action: send, schedule, preview.

Numbers are given plainly, without adjectives around them.
